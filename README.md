# Автономная шахматная доска (Autonomous Chess Board)

Проект создания роботизированной шахматной доски для курса **MIPT FAB**. Доска оснащена скрытой двухкоординатной механикой CoreXY с электромагнитом под игровым полем, которая автоматически перемещает шахматные фигуры с неодимовыми магнитами в основании.

## Архитектура проекта

Система состоит из следующих ключевых узлов:
1. **Механическая подсистема**:
   - Двухосевая кинематика **CoreXY** на двух независимых ремнях GT2 (ширина 6 мм).
   - 2 шаговых двигателя **NEMA 17** (17HS4023), жестко закрепленных на нижней плите корпуса в нижнем левом и нижнем правом углах.
   - Линейные направляющие: 4 стальных прецизионных стержня $8 \times 500$ мм и 4 линейных подшипника SCS8UU.
   - Ведущие шкивы GT2 20T на валах двигателей, паразитные зубчатые и гладкие натяжители GT2.
   - Корпус из лазерной фанеры толщиной 6 мм и детали креплений, напечатанные на 3D-принтере.
2. **Исполнительный орган**:
   - Подвижная каретка с компактным электромагнитом.
   - Управление питанием электромагнита через силовой N-канальный MOSFET-транзистор **IRLZ44N** с логическим уровнем управления затвором.
3. **Электронный блок управления**:
   - Одноплатный компьютер **Raspberry Pi Zero 2W**.
   - 2 драйвера шаговых двигателей **DRV8825** с платами расширения (Shields), настроенные на микрошаг $1/16$.
   - Плата расширения портов **MCP23017** (I2C) и матрица из 64 герконов под клетками поля для регистрации перемещения фигур игроками.

## Геометрия поля и рабочая зона

Каретка перемещается под фанерным игровым полем.

```
       0 мм (X)                                     420 мм (X)
0 мм (Y)+-----------------------------------------------+
        |             Верхний зазор: 44 мм              |
        |  +-------+-------------------------+-------+  |
        |  |       |    Шахматное поле       |       |  |
        |  |Кладб. |   8 колонок (A - H)     |Кладб. |  |
        |  |слева  |                         |справа |  |
        |  | 2 кол.|   8 рядов (1 - 8)       | 2 кол.|  |
        |  | (68мм)|      (272 мм)           | (68мм)|  |
        |  +-------+-------------------------+-------+  |
        |             Нижний зазор: 44 мм               |
360 мм  | [Мотор L]                           [Мотор R] | 
  (Y)   +-----------------------------------------------+
```

- **Рабочая область движения каретки**:
  - По горизонтали ($X$): от **0 до 420 мм** (слева направо).
  - По вертикали ($Y$): от **0 до 360 мм** (сверху вниз, в сторону моторов).
- **Размер одной клетки**: **$34.0 \times 34.0$ мм**.
- **Сетка полей**:
  - Всего по горизонтали: **12 колонок** (2 колонки слева — кладбище белых/черных фигур, 8 колонок — поле $A..H$, 2 колонки справа — второе кладбище). Ширина: $12 \times 34 = 408.0$ мм.
  - Всего по вертикали: **8 рядов** (линии 1..8). Высота: $8 \times 34 = 272.0$ мм.
- **Центрирование поля в рабочей области**:
  - Боковые отступы (слева/справа): $(420 - 408) / 2 = \mathbf{6.0\text{ мм}}$.
  - Верхний и нижний отступы: $(360 - 272) / 2 = \mathbf{44.0\text{ мм}}$.
- **Начальная точка $(0, 0)$**: верхний левый угол (Top-Left). На текущем этапе каретка устанавливается в него вручную перед подачей питания.

## Аппаратная часть и распиновка

### Подключение к 40-пиновому разъему Raspberry Pi Zero 2W

| Функция | Модуль / Компонент | BCM пин (GPIO) | Физический пин RPi | Примечание |
|---|---|---|---|---|
| **STEP** | Драйвер DRV8825 Левый | `GPIO 17` | Pin 11 | Импульсы шага (Motor L / A) |
| **DIR** | Драйвер DRV8825 Левый | `GPIO 27` | Pin 13 | Направление вращения |
| **ENABLE** | Драйвер DRV8825 Левый | `GPIO 22` | Pin 15 | Активный 0 (LOW = включен) |
| **STEP** | Драйвер DRV8825 Правый | `GPIO 23` | Pin 16 | Импульсы шага (Motor R / B) |
| **DIR** | Драйвер DRV8825 Правый | `GPIO 24` | Pin 18 | Направление вращения |
| **ENABLE** | Драйвер DRV8825 Правый | `GPIO 25` | Pin 22 | Активный 0 (LOW = включен) |
| **GATE** | Транзистор IRLZ44N | `GPIO 18` | Pin 12 | Управление электромагнитом (PWM0) |
| **SDA** | Расширитель MCP23017 | `GPIO 2` | Pin 3 | Шина I2C (для матрицы герконов) |
| **SCL** | Расширитель MCP23017 | `GPIO 3` | Pin 5 | Шина I2C (для матрицы герконов) |
| **GND** | Общая земля | `GND` | Pin 6, 9, 14, 20... | Объединить с землей питания моторов |

> [!IMPORTANT]
> **Пин Enable на DRV8825**: имеет инверсную логику:
> - `0` (`LOW`) — драйвер **активирован**, на обмотки моторов подается ток удержания.
> - `1` (`HIGH`) — драйвер **обесточен**, вал свободно вращается. Скрипты автоматически переводят драйверы в `HIGH` после завершения перемещений, чтобы моторы и драйверы не нагревались во время пауз.

> [!NOTE]
> **Обвязка транзистора IRLZ44N**:
> - Резистор 220 Ом включен последовательно между GPIO 18 и затвором (Gate) транзистора для защиты выхода Raspberry Pi от токовых бросков перезаряда емкости затвора.
> - Резистор 1 кОм (или 10 кОм) включен между затвором (Gate) и землей (GND) в качестве стягивающего (pull-down), чтобы электромагнит гарантированно не включился самопроизвольно при перезагрузке микрокомпьютера.

## Кинематика CoreXY и расчет шагов

### Расчет разрешения привода (Steps/mm)
- Угол шага двигателя NEMA 17: $1.8^\circ \implies 200$ полных шагов на один оборот.
- Настройка микрошага DRV8825: **$1/16$** (все три перемычки MS1, MS2, MS3 замкнуты на высокий уровень).
- Количество микрошагов на оборот: $200 \times 16 = \mathbf{3200\text{ шагов/оборот}}$.
- Ведущий шкив GT2: 20 зубьев с шагом 2.0 мм. Перемещение за один оборот: $20 \times 2.0 = \mathbf{40.0\text{ мм/оборот}}$.
- **Разрешение (шагов на мм)**:
  $$\text{STEPS\_PER\_MM} = \frac{3200}{40.0} = \mathbf{80.0\text{ шагов/мм}}$$

### Уравнения перемещения CoreXY
В схеме CoreXY перемещение каретки в декартовых координатах $(\Delta X, \Delta Y)$ реализуется одновременным вращением левого (A) и правого (B) двигателей:
$$\Delta A = \Delta X + \Delta Y$$
$$\Delta B = \Delta X - \Delta Y$$

- Движение строго вправо ($+X$): оба мотора вращаются синфазно ($\Delta A > 0, \Delta B > 0$).
- Движение строго вниз ($+Y$, в сторону моторов): моторы вращаются в противоположные стороны ($\Delta A > 0, \Delta B < 0$).
- Диагональное движение: вращается только один из моторов (например, при $\Delta X = \Delta Y$ вращается только мотор A).

## Установка и настройка ПО

Скрипты управления используют демон `pigpio`, обеспечивающий аппаратную точность импульсов без задержек операционной системы Linux.

### 1. Установка pigpio на Raspberry Pi OS

**Вариант А (из репозитория apt):**
```bash
sudo apt update
sudo apt install -y python3 python3-pip pigpio python3-pigpio git
```

**Вариант Б (сборка из исходников, например для Debian Trixie / Bookworm):**
```bash
sudo apt update
sudo apt install -y git build-essential python3-setuptools
git clone https://github.com/joan2937/pigpio.git
cd pigpio
make
sudo make install
sudo ldconfig
```

### 2. Запуск демона pigpiod
```bash
# Запуск демона вручную:
sudo pigpiod

# Или через systemd (если доступен сервис):
sudo systemctl enable --now pigpiod
```

### 3. Клонирование репозитория
```bash
git clone https://github.com/hebeieh/autonomous_chess.git
cd autonomous_chess
```

## Тестирование механики (test_motors.py)

Для первоначальной пусконаладки и проверки правильности подключения моторов подготовлен скрипт `test_motors.py`.

### Подготовка перед запуском теста
1. **Обесточьте моторы**.
2. **Вручную передвиньте каретку** с электромагнитом в верхний левый угол рабочей зоны ($X=0, Y=0$).
3. Убедитесь, что каретка имеет свободный запас хода минимум **60 мм вправо (+X)** и **60 мм вниз (+Y)** без упора в стенки и подшипники.
4. Подайте силовое питание (12V) на драйверы моторов.

### Запуск базового теста
```bash
python3 test_motors.py
```

### Что выполняет скрипт:
1. **Включение драйверов**: подает `LOW` на пины `enable_pin` (22 и 25). Моторы встают на удержание.
2. **Тест левого мотора (L)**: делает пробное движение на $+10$ мм и возвращается на $-10$ мм (каретка двигается по диагонали).
3. **Тест правого мотора (R)**: делает пробное движение на $+10$ мм и возвращается на $-10$ мм (каретка двигается по второй диагонали).
4. **Декартов контур (квадрат 50х50 мм)**:
   - Шаг 1: $+50$ мм вправо по оси $X$.
   - Шаг 2: $+50$ мм вниз по оси $Y$ (к моторам).
   - Шаг 3: $-50$ мм влево по оси $X$.
   - Шаг 4: $-50$ мм вверх по оси $Y$ (возврат точно в исходную точку $0,0$).
5. **Тест электромагнита**: кратковременно включает транзистор IRLZ44N на 1.5 секунды и выключает.
6. **Обесточивание**: переводит `enable_pin` в `HIGH`, позволяя моторам свободно вращаться и остывать.

### Дополнительные параметры запуска
```bash
# Запуск в режиме эмуляции на ПК (без реального подключения к pigpiod):
python3 test_motors.py --dry-run

# Изменение скорости движения (по умолчанию 25 мм/с):
python3 test_motors.py --speed 15.0

# Изменение размера тестового квадрата (например, 30 мм):
python3 test_motors.py --distance 30.0

# Пропустить проверку одиночных моторов:
python3 test_motors.py --skip-singles

# Пропустить тест электромагнита:
python3 test_motors.py --skip-magnet
```

### Калибровка направления движения
Если при движении «вправо» каретка поехала в другую сторону:
1. Откройте файл `config.py`.
2. Измените флаги инверсии направления для соответствующего двигателя:
   - Для левого мотора: `MOTOR_LEFT.invert_dir = True`
   - Для правого мотора: `MOTOR_RIGHT.invert_dir = True`
   *(Либо переверните разъем 4-пинового кабеля шагового мотора на шилде на 180° при отключенном питании).*
