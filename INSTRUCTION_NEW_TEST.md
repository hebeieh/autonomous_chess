# Инструкция по запуску скрипта `new_test.py`

Скрипт [`new_test.py`](file:///home/bulat/projects/diana/chess_project_upd/autonomous_chess/new_test.py) предназначен для быстрой изолированной проверки вращения шагового двигателя NEMA 17 (17HS4023) и драйвера DRV8825 с помощью библиотеки `RpiMotorLib` и модуля `RPi.GPIO`.

По умолчанию в скрипте настроены пины **левого мотора (Motor L)**:
- **DIR** (направление): `GPIO 27` (Pin 13)
- **STEP** (шаг): `GPIO 17` (Pin 11)
- **ENABLE** (включение драйвера): `GPIO 22` (Pin 15)

---

## 1. Установка необходимых зависимостей

Скрипт требует наличия двух библиотек:
1. `RPi.GPIO` (или совместимого `rpi-lgpio`)
2. `RpiMotorLib`

### Настройка на Raspberry Pi OS (Debian Trixie / Bookworm)

В современных версиях Debian/Raspberry Pi OS действует защита `PEP 668` (externally-managed-environment), а доступ к GPIO управляется через подсистему `lgpio`.

#### Шаг 1. Установка системных пакетов и библиотеки GPIO
Выполните в терминале Raspberry Pi:
```bash
sudo apt update
sudo apt install -y python3-pip python3-setuptools
# Рекомендуемый совместимый пакет GPIO для Debian Bookworm / Trixie:
sudo apt install -y python3-rpi-lgpio
```

#### Шаг 2. Установка `RpiMotorLib`

**Вариант А (через флаг `--break-system-packages`, самый быстрый способ):**
```bash
pip3 install --break-system-packages rpimotorlib
```

**Вариант Б (в изолированном виртуальном окружении `venv`):**
```bash
# Создание окружения с доступом к системным пакетам:
python3 -m venv --system-site-packages ~/chess_venv
# Активация окружения:
source ~/chess_venv/bin/activate
# Установка библиотеки:
pip install rpimotorlib
```

## 2. Подготовка оборудования перед запуском

> [!IMPORTANT]
> **Меры безопасности**:
> 1. Убедитесь, что каретка механики не упирается в край корпуса. Вращение 200 шагов в полношаговом режиме соответствует перемещению ремня примерно на **40 мм**!
> 2. Обеспечьте запас хода каретки не менее 50 мм в обе стороны.
> 3. Убедитесь, что силовое питание драйверов (12 В) включено, а земля (GND) источника питания объединена с землей Raspberry Pi.

## 3. Запуск скрипта

Перейдите в директорию проекта и запустите скрипт:

```bash
cd ~/autonomous_chess  # или путь к вашей папке с проектом
python3 new_test.py
```

*Примечание: Если скрипт сообщает об ошибке прав доступа к `/dev/gpiomem` или портам ввода/вывода, запустите с правами суперпользователя:*
```bash
sudo python3 new_test.py
```

## 4. Что происходит во время работы скрипта

1. `GPIO.output(EN_pin, GPIO.LOW)` — на пин 22 подается низкий уровень. Драйвер DRV8825 активируется, обмотки двигателя встают под ток удержания.
2. `mymotortest.motor_go(...)` — мотор делает **200 шагов** (1 полный оборот вала) против часовой стрелки (`False`) в полношаговом режиме (`"Full"`) с задержкой 0.5 мс между импульсами.
3. `GPIO.cleanup()` — порты GPIO сбрасываются в исходное состояние, обмотки обесточиваются (вал снова можно свободно вращать рукой).

## 5. Как переключить тест на правый мотор (Motor R)

Если вам нужно проверить правый мотор, откройте файл `new_test.py`:
```bash
nano new_test.py
```

Найдите строки 22–24:
```python
direction = 27 # Direction (DIR) GPIO Pin
step = 17      # Step GPIO Pin
EN_pin = 22    # enable pin (LOW to enable)
```

И замените их на пины правого двигателя:
```python
direction = 24 # Правый мотор DIR
step = 23      # Правый мотор STEP
EN_pin = 25    # Правый мотор ENABLE
```
Сохраните изменения (`Ctrl+O`, затем `Enter`) и выйдите (`Ctrl+X`), после чего запустите скрипт повторно.

## 6. Возможные проблемы и их решения (Troubleshooting)

### 1. `ModuleNotFoundError: No module named 'RpiMotorLib'`
Библиотека не установлена в текущем окружении Python.
**Решение:** Выполните:
```bash
pip3 install --break-system-packages rpimotorlib
```

### 2. `RuntimeError: No access to /dev/mem` или `Cannot determine SOC peripheral base address`
Стандартный `RPi.GPIO` не может получить доступ к регистрам на новом ядре Linux в Debian Trixie.
**Решение:** Установите библиотеку-прослойку `rpi-lgpio`:
```bash
sudo apt remove -y python3-rpi.gpio
sudo apt install -y python3-rpi-lgpio
```

### 3. Двигатель только пищит / вибрирует, но не крутится
- **Причина 1: Слишком высокая скорость для старта без разгона.** В строке 38 указана задержка `.0005` (500 мкс), что дает частоту 2000 шагов/с (10 об/с в полношаговом режиме). Мотор NEMA 17 без плавного разгона может срываться в пропуск шагов.
  - **Решение:** Увеличьте задержку до `0.002` или `0.003` сек (строка 38 в `new_test.py`):
    ```python
    .002, # step delay [sec]
    ```
- **Причина 2: Недостаточный ток (Vref) на драйвере DRV8825.** Настройте подстроечный резистор на плате драйвера (обычно около $0.6 - 0.8$ В в зависимости от сопротивления токоизмерительных резисторов).
- **Причина 3: Перепутаны фазы мотора.** Проверьте правильность подключения пар проводов обмоток A и B к плате расширения.
